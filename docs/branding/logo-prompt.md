# Oceania Youth 2027 logo

Generated with the built-in image generation tool, using `public/hero.png` as a visual reference. Icon sizes were exported from the generated transparent PNG.

## Final prompt

Use case: logo-brand. Create one new premium compact emblem for the Oceania Youth Chess Championship website. The attached hero banner is a color and subject reference only, not an edit target. Design a single bold ivory chess knight silhouette rising above two sweeping ocean waves in turquoise and warm ochre gold, inside a deep ocean teal circular disc with one restrained gold outer arc. Flat vector-like clean silhouette, strong negative space, harmonious confident sporting event identity. Reference palette deep teal #003d40, turquoise #2c989b, ivory #fff8e8 and warm gold #c59439. Center emblem, fills about 90% of square canvas, genuinely transparent outside circular emblem. The knight must be instantly recognizable at favicon size. No letters, no words, no numbers, no map, no tiny details, no gradients, no shadows, no mockup. Interpret ocean rhythm and Australian/Oceania setting without reproducing the banner's detailed dot artwork. Deliver one finished logo emblem, not a sheet of options.
