# French translation draft

Status: DRAFT, prepared for language review. No federation approval is claimed.

The flat dictionary contains 948 English-to-French string entries. Coverage includes the shared header, footer, search and accessibility labels; primary page headings and copy; registration fees and timeline; contact form and errors; player directory controls; broadcast controls and settings; home, venue and organiser data; the complete published regulations prose and tables; federation support conditions; sponsors; and all text nodes of the three current news articles.

Keys use rendered text with collapsed whitespace and decoded JSX entities. Short source clauses support text separated by JSX elements or dynamic values. No invented interpolation placeholders are used. Dates retain their original numeric values. Names, IDs, addresses, URLs, email addresses, chess notation and numerical data are preserved.

The current English site contains different statements about visa refunds and official accommodation across the regulations, federation-support and promotional pages. This draft preserves each source statement; organisers should resolve the source discrepancies before approving translations. Chess titles and direct-title eligibility, tiebreak terminology, fee conditions and assistance conditions merit specialist review.

PDFs, SVG artwork containing embedded English text, external registration services, browser-native validation, and external broadcast/player content are outside this dictionary. Alternative text for the registration diagram is translated. Proper names and text not matched by an exact dictionary key may remain in English. New source wording requires a new matching entry.

Validation: JSON parses as a flat object with nonempty string keys and values; all three static news articles have translations for every English HTML text node. Primary component text and attributes were checked against the dictionary; remaining omissions are names, addresses, identifiers or deliberately preserved branding.
